# 아파트 대장 비교

지역과 아파트를 고르면 그 지역 대장 아파트와 실거래가·고점·저점·사이클을 나란히 보여 주는 개인용 웹사이트입니다.

- 실거래가: 국토교통부 아파트 매매 실거래가 API(공공데이터포털). 인증키는 사용하는 기기의 브라우저에만 저장되고, 자료는 브라우저가 직접 받습니다.
- KB시세·호가·세대수: KB부동산이 로그인 없이 보여 주는 값을 그때그때 받습니다.
- `data/seed.json`: 미리 담아 둔 6개 단지 실거래(2006~2026년 10월)와 지역 지수, 정권·정책·금리 연표.
- `data/regions.json`: 시·도, 시·군·구 코드(국토교통부 API의 LAWD_CD).

파일 구성: `index.html`(화면) · `style.css` · `app.js`(화면 동작) · `analysis.js`(계산 규칙) · `api.js`(자료 가져오기·저장).
